# RNA-Seq-Reader
This application lets users create an account and log in securely; once logged in, users can open and read FASTQ files, trim reads, and generate a report on the file's contents.

## Features
- Parse FASTQ files
- Trim adapters and low-quality bases
- Generate a QC report
- History Tracking - view and download past reports generated
